One sentence (182 characters) that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun. The entry is the whole program's output: `main.ts` writes the pitch to `/output/entry.txt`.

> You've told friends about your app idea a hundred times — tell it once more to an AI agent on make.fun and it'll build you a working app tonight, no code, no course, nothing to lose.

The angle: the friend has already done the only hard part — describing the idea out loud, a hundred times, to friends. The agent just needs that same description, once more. Six variants were drafted and judged against the rubric (persuasion, clarity, truth, warmth and craft); this one won for its concrete reason to say yes now ("tonight"), its low-risk close ("nothing to lose"), and a turn of phrase no template would produce.

## Run it

```sh
node main.ts
```

This writes the pitch to `/output/entry.txt` and prints its character count (182, within the 1–240 gate). Requires Node 22.18 or later; no dependencies to install.
